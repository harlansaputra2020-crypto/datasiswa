EduData

Aplikasi Data Siswa · Versi 1.0

EduData merupakan rancangan aplikasi antarmuka untuk membantu pengelolaan data siswa secara lebih terstruktur, sederhana, dan mudah digunakan oleh tenaga pendidik. Proyek ini dibuat sebagai penerapan pembelajaran GUI dan prinsip UI/UX.

Fitur utama

  • Pengelolaan data siswa (tambah, lihat, edit, hapus).
  • Pencarian data dan filter berdasarkan kelas.
  • Ringkasan statistik siswa pada dashboard.
  • Pencatatan absensi: Hadir, Izin, Sakit, dan Alpa.
  • Tampilan contoh jadwal pelajaran.
  • Penyimpanan data lokal pada browser.
Dibuat untuk projek pembelajaran Perancangan GUI Aplikasi Data Siswa. Data disimpan di browser yang sedang digunakan dan bukan di server/database sekolah.
